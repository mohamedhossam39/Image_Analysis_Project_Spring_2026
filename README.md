Computer Vision Sudoku Solver


An end-to-end Computer Vision and Intelligent Systems pipeline engineered to capture, isolate, parse, and solve Sudoku puzzles from noisy real-world images. 
This project achieves execution without relying on machine learning frameworks, adhering strictly to algorithmic image processing and pattern matching techniques. The Project was able to solve most attached test cases but the OCR still needs further fine-tuning to be able to solve the most extreme edge-cases.
